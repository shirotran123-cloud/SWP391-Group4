2. Trần Công Tiến – DevOps & Security Engineer
Trọng tâm: Hoàn thiện máy chủ chấm thi Docker Sandbox và tự tấn công thử nghiệm (Self-Penetration Testing) để chuẩn bị nghênh chiến nhóm đối thủ tại Tuần 5.
Nhiệm vụ cụ thể (Tasks):
Viết Worker Service điều khiển Docker Engine: Lập trình Node.js/TypeScript sử dụng thư viện dockerode để tự động hóa: tạo container $\rightarrow$ copy code vào $\rightarrow$ chạy lệnh biên dịch $\rightarrow$ nạp StdIn/StdOut $\rightarrow$ dọn dẹp container (docker rm -f -v $\le 1.0$s).
Đóng gói Base Images cho 4 ngôn ngữ: Xây dựng Dockerfile chuẩn hóa cho: Java 17 OpenJDK, Python 3.11, C/C++ (GCC 11) và .NET 8.0 SDK.
Kích hoạt lá chắn bảo mật: Ép thông số cứng vào container: --network none, -m 512m, --cpus 1.0, --pids-limit 64, và gắn file bộ lọc seccomp.json chặn 44 system calls nguy hiểm.
Thực hiện bài test "Tự hack Sandbox của nhóm": Viết sẵn 3 file code độc hại nộp thử vào hệ thống:
File 1: Vòng lặp vô hạn while(true) $\rightarrow$ Kiểm tra xem Watchdog 2.0s có bắn hạ SIGKILL (TLE) chuẩn không.
File 2: Xin cấp phát 5GB RAM (malloc) $\rightarrow$ Kiểm tra xem Linux OOM Killer có dập tắt (MLE - exit 137) chuẩn không.
File 3: Lệnh Fork Bomb (while(1) fork();) và đọc trộm file .env $\rightarrow$ Kiểm tra xem Seccomp có chặn đứng ngay lập tức không.
Sản phẩm đầu ra (Definition of Done):
4 Docker images hoàn thiện.
Worker chấm code tự động, trả về đúng stdout, stderr, time_ms, memory_kb.
Vượt qua 100% các bài test tự tấn công mà máy chủ host không bị sập hay rò rỉ RAM.

3. Trần Thanh Nguyên – RBL Research Lead (AST & Winnowing Core)
Trọng tâm: Lập trình hoàn thiện thuật toán trích xuất Cây cú pháp AST và giải thuật băm Winnowing để tính ma trận đạo văn của lớp.
Nhiệm vụ cụ thể (Tasks):
Lập trình Module AST Normalizer: Sử dụng parser (Tree-sitter hoặc module ast của Python) để tước bỏ toàn bộ tên biến, tên hàm, chú thích; thay thế bằng các token chuẩn hóa (VAR_DECL, BIN_OP, FOR_LOOP) để chống chiêu trò ngụy trang mã nguồn.
Lập trình Giải thuật Winnowing:
Cắt chuỗi token thành các $k$-grams ($k=15$).
Chạy cửa sổ trượt ($w=10$) chọn các giá trị băm nhỏ nhất làm vân tay số (hash_value).
Lưu các vân tay kèm line_start, line_end vào bảng AST_FINGERPRINTS.
Hàm tính ma trận tương đồng Jaccard: Viết logic tính $\text{similarity_rate} = \frac{|F_A \cap F_B|}{|F_A \cup F_B|} \times 100%$ giữa tất cả các cặp bài nộp trong lớp; tự động lưu các cặp $\ge 70%$ vào PLAGIARISM_REPORTS và xuất tọa độ matched_tokens_json.
Chuẩn bị bộ dữ liệu thực nghiệm: Thu thập và tạo thử 10 cặp code bị AI ngụy trang (đổi biến, viết lại logic) để chứng minh thuật toán đạt độ chính xác $> 80%$ cho bài báo cáo RBL.
Sản phẩm đầu ra (Definition of Done):
Module AST + Winnowing chạy độc lập với tốc độ $< 200$ms cho một file code 500 dòng.
Tính toán và xuất được ma trận tương đồng giữa 2 bài nộp bất kỳ.
